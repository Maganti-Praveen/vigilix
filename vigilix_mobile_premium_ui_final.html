Vigilix / mobile-first redesign

Design direction

This version is intentionally built around a narrow phone viewport. The UI uses restrained colors, premium line icons, native-style spacing, soft materials and motion that feels like a polished product rather than a concept dashboard.

Mobile-firstNo emojisPremium iconsNative feelDark + Light capable
Design principle: use one primary accent, not five competing colors. Let hierarchy come from typography, spacing, opacity and surface depth. Status colors appear only when the state matters.
Icon language
Monoline system icons
16–22 px

Use a consistent Lucide-style / SF-symbol-like icon family. Camera, viewer, torch, microphone, recording, battery, wifi, settings, back and navigation icons should all share the same stroke language.

Motion language
Quiet, responsive motion
200–900 ms

Splash gets the richest animation. Normal navigation stays around 250–350 ms. Live status gets subtle pulses. Avoid motion on every card just for decoration.
